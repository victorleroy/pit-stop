# Code of conduct

Pit Stop follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good faith, criticise code rather than people, and no harassment of
any kind, in issues, pull requests or anywhere the project is discussed.

Report unacceptable behaviour privately to the maintainer, at the address shown on
[their GitHub profile](https://github.com/victorleroy). Reports are read, kept confidential,
and answered. The maintainer may remove comments, close threads or block anybody who does not
respect these rules.
